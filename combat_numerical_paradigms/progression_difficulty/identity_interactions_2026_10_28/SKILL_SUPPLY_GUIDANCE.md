# 身份技能供给的必要条件

2026-10-28。以下是结合实际触发覆盖与既有规则得出的配表检查项。具体强度预算和最优顺位收益仍参考原联测与最优顺位研究；这里保留现有生成器参数。

| 身份/机制 | 配表时必须能成立的条件 | 应核对的实际结果 |
|---|---|---|
| 女仆长 | 保证发动会结束当次全队检索；需要先释放的其他技能须位于其前，或另有可达的行动机会 | 各身份真实出手次数，女仆长之前的检索覆盖 |
| 学者 | 至少一名非女仆长队友有有限次数、已经消耗，且仍有利用恢复次数的机会 | 恢复次数、恢复后实际再施放；本批5人样本无有限次技能，恢复为0 |
| 剑士 | 至少另一名剑士在当前回合满足原门槛并有剩余次数 | 实际追加技能数、被消耗的次数、衰减后的链长，最多3次追加 |
| 工程师 | 队伍装备确实贡献四维，且工程师技能能发动，战斗还能进入后续回合 | gearStats、已提交增长、之后实际使用；只有护盾或技能机制的装备不能提供四维基数 |
| 忍者 | 主动增长需要忍者真实发动技能，并从下回合开始利用 | 排队增长、下一回合绝对闪避；开局绝对闪避单独记账 |
| 魔法师 | 同流派第二次实际施法才增加百分比层；与上次不同的实际技能才增加切换层 | 同流派层数、切换次数、百分比通道实际存在；普攻不产生技能层 |
| 农民 | 能完成播种→成熟后再次攻击；加速本身不在同次攻击收获 | 播种、加速、成熟时间、收获次数及实际回复/属性增量；只播种不收获不算完整收益 |
| 侠女 | 首次技能之后，仍有后续侠女技能施放机会，包括同一侠女重复施放 | 首次层数、后续使用层数的技能次数 |
| 学生/老师 | 存在实际学生及其培养等级，老师技能能进入检索结果 | 学生等级总和、老师攻击增益；学生经验倍率交由奖励业务结算 |
| 拜火教 | 高阶技能的持有者与低阶教徒共存；低阶按技能tier判断 | 实际低阶人数、获得加成的高阶技能施放，而非只看人物标签阶位 |
| 淑女 | 被强化的是前部覆盖位置的实际技能 | 位置覆盖与实际施放；当前候选不加成随机保底普攻 |
| 军人 | 军人数至少为阶段人数上限的一半，按上限计算 | 5/10/15/20/25/30阶段最低分别3/5/8/10/13/15名；再统计强制命中事件 |
| 猎手 | 转出折前直伤后，战斗有机会进入后续回合 | 预约真伤、实际结算和战斗结束未兑现量分别记账 |
| 杀手 | 命中标记后对方下一次实际技能确有恢复请求，才产生减疗收益 | 标记数与healingPrevented分开；非恢复技能也会消费标记 |
| 富翁 | 产币后仍承受后续伤害 | 本场金币与richSaved分开；产币不等于已减伤 |
| 盗贼 | 对方有效四维仍有可转移量，偷取后还有施放或防御机会 | 每维实际转移及后续使用；只改本场属性 |
| 社畜 | 装备保命结束后仍出现首次战力<=0 | 实际复起事件；不能把装备保命和社畜对同一次伤害重复预算 |
| 冒险者 | 目标包中存在可完成节点，完成后仍有冒险者技能出手机会 | 完成节点与增强后施法数分开；当前达标技能不追溯增伤 |
| 帮派 | 原技能发动概率仍决定是否选中，选中后替换普攻 | 帮派替换攻击及普攻装备收益；原技能附加效果、技能装备和技能次数不参与 |
| 格斗家 | 队伍能进入后续回合，实际输出或原生读取源输出的流失仍在发生 | 回合成长及实际利用的后续伤害 |

这些必要条件可以直接用于技能供给检查：先核对效果是否有目标、能否触发、能否兑现，再对有效收益定预算。对学者、工程师、农民、杀手等机制，单独提高人数系数无法弥补没有目标或没有后续行动的供给缺口。
