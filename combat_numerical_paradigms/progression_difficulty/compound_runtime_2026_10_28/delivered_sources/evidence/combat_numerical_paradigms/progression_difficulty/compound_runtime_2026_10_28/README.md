# 女仆长、共享果实、冒险目标接入

2026-10-28。三项按复合效果研究版本接入，23项身份机制均有可选运行时实现。完整调用方式见[23项接入指南](../IDENTITY_RUNTIME_INTEGRATION.md)。

## 女仆长

最前女仆忽略原发动率、次数、回合与战力百分比门槛，替换数值技能后应用其本人装备，保留实际发动次数记录。原技能不被永久改写。独立回复在施法时发生，后续未命中也保留；仍受杀手下一技能减疗及本人恢复/溢出装备影响。增加四维在动作结束后发生，按开局各维固定基数累加。

q=n/(n+4)。五个效果候选在q达到0.2/0.4/0.55/0.7/0.8时解锁，对应1/3/5/10/16名女仆；可配置maidUnlocks。原生勇气暴击继续存在，第4档增加的是技能基础暴击率。

| 通道 | 当前可调候选，s=maidBudget |
|---|---|
| 基础攻击 | 100%×(1+1.8qgs) |
| 施法回复 | 最大战力×0.08qgs，含本人恢复装备 |
| 每次各维增长 | 开局该维×0.025qgs |
| 敌方四维削弱 | 12qgs%，2回合，继续走魔力/贤者与原生上限 |
| 新增技能暴击率 | 0.20qgs |
| 附加真伤 | 命中后另加该次折前直伤×0.35qgs；不再额外乘魔力，仍走护盾/吸收/金币减伤/保命 |

maidAdditionalTrue默认true；false保留已测的整段原生纯真伤对照。maidBudget默认1表示完整候选，调用方应依据阶段机会成本选已测预算，不表示满队全阶段都推荐1。所有羁绊布尔默认关闭。

## 果实

全队一个共享果实。第一次农民攻击播种，ready=当前回合+5；未成熟时每次农民攻击把ready减少1，最低到当前回合，本次只加速；之后成熟攻击才收获。收获后清空，下一次攻击重新播种。攻击不要求命中。

W=1+0.15×成熟后等待回合；回复最大战力×0.12qgW，独立于技能减疗；各维增量=开局四维均值×0.10qgW。可增强的属性种类在q达到0/0.4/0.6/0.8时为1/2/3/4种；按开局低属性优先，等值按勇气/坚韧/先机/魔力。门槛、数值与等待倍率均可配置。不开新战力上限，不改角色档案。

## 冒险目标

默认六目标：敌方首次严格低于100/75/50/25%战力、首次暴击、首次闪避。目标包可配置；四血线包可配每目标0.09，其余默认每目标0.06，满完成奖励均为0.36qg。奖励只增强之后冒险者技能基础攻击，当前达标技能不追溯增强。

全队共享，每场每目标一次，回血不重置，同一击跨多线可完成多项。血线在装备保命/社畜回复前记录。额外观察首次命中、有效回复、流失施加、负面施加、绝对闪避，可以配置为目标。防守闪避即时登记；有效回复才触发首次回复，满血溢出不算有效回复。
