# 魔法师、猎手、帮派、富翁、社畜接入

q=n/(n+4)，g为gain，均可配置。

| 身份 | 已接入候选 |
|---|---|

随机保底普攻选到帮派时不额外触发“选中帮派替换技能”的增幅；这保留既有研究候选的触发口径。法师记录所有实际技能，不强制角色必须选两种流派。转换真伤仍受护盾、全域吸收、富翁减伤和保命影响，不重复乘魔力或输出倍率。

金币在新战斗重置，只导出结果coins供调用方结算；不自动入账。中断结果也可能带累计值，不应据此重复发放。战报coinsEarned记录本次获取，isNormalAttack明确普通攻击及帮派替换攻击。

回合开始持续伤害已经结束战斗时，立即跳过先机同速抽签，不再消耗无用随机数。新增定向检查覆盖这一边界。
