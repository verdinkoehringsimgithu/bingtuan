# 技能词条与特效配对优化

日期：2026-10-14。适用于根目录技能生成器及主Unity项目的 SkillEffectMatcher。

## 配对规则

高阶六字名称先识别整体意象，再识别动作。例如“究极斩击风暴”使用旋风球乱舞爆炸，“苍穹坠击陨星”使用冲天爆破气柱，“极限连刺骤雨”使用羽状扩散打击；不会仅因含有斩击、坠击或连刺就固定到普通刀斩或撞击。

同类爆炸、烟雾、雷电、聚合、打击等可在语义相近的特效中稳定选择。候选必须通过流派与投放限制；原始类型可用时，候选保持相同的自身／敌方目标。剑、爪、传送门、引力等明确形态保持专属配对。

颜色优先依据名称前部的元素与材质，再参考中部和整体名称。劫灰、钢铁、磐石等可使用灰色；土石尘埃可使用棕色；高阶混沌、幻梦等可使用彩虹。候选优先保留匹配颜色，缺色时按明确的近似色顺序选择。确定性哈希保证同名、同流派、同阶技能结果可复现。

## 验证结果

冻结随机种子314159生成同一份24000条名称：四维流派×T1～T6×每组1000条。优化前后均在此语料上比较。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 使用特效类型 | 63/63 | 63/63 |
| 使用变体 | 376/467 | 427/467 |
| 使用最多五类占比 | 33.05% | 27.47% |
| 不合法配对 | 0 | 0 |

使用变体比例由80.5%增至91.4%。该语料的覆盖统计不能替代所有技能的视觉审阅，也不以强行使用全部颜色为目标。

另验证12000条实际生成技能、384条既有跨端配对、24000条冻结语料及11条明确语义回归样例。Unity工具合计27525项检查通过，涵盖63类467变体及19个前后层变体。

证据位于 `effect_tuning/matching_improvement_summary.json`、`matching_family_coverage.csv`、`matching_before.tsv`、`matching_after.tsv`、`matching_examples_before.tsv`、`matching_examples_after.tsv`、`generator_validation.json` 与 `visual_validation.json`。

## 生效方式

新生成技能使用优化规则。已赋予有效特效ID的技能，正式播放时保留该ID；如需重新配对已有表，在生成器使用现有“全表智能刷新特效ID”按钮，检查后保存CSV。

主项目源码与根目录生成器程序已更新。用户正在检查的 `.gemini/battle_scene_validation` 项目本轮未同步，避免脚本重载打断测试。用户保存的时点、位置、缩放、排序与自身／敌方配置继续保留；本轮只调整词条匹配，不重烘焙图片、不改动画ID、不改战斗数值。
